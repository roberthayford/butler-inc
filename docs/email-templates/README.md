# Email Templates

Branded HTML email templates for use in Supabase Authentication.

## Templates

| Template | Description | File |
|----------|-------------|------|
| Confirm Signup (Text Logo) | Account confirmation email with text-based "Butlers Inc." logo | [confirm-signup-text-logo.md](./confirm-signup-text-logo.md) |
| Confirm Signup (Image Logo) | Account confirmation email with image-based logo (requires hosted URL) | [confirm-signup-image-logo.md](./confirm-signup-image-logo.md) |
| Reset Password (Text Logo) | Password reset email with text-based "Butlers Inc." logo | [reset-password-text-logo.md](./reset-password-text-logo.md) |
| Reset Password (Image Logo) | Password reset email with image-based logo (requires hosted URL) | [reset-password-image-logo.md](./reset-password-image-logo.md) |

## Usage

1. Copy the HTML from the relevant template file
2. In Supabase Dashboard, go to **Authentication > Email Templates**
3. Select the **Confirm signup** tab
4. Paste the HTML into the template body
5. Save
